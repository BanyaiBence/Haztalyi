# Haztalyi

A small farming game made with [LÖVE](https://love2d.org) 11.5.

```sh
love src
```

| Key | Action |
|---|---|
| WASD / arrows | move |
| Space / E | till grass, plant the selected seed, harvest a ripe crop |
| 1–4, Q / Tab | choose seed |
| Esc / P | pause |

See [docs/architecture.md](docs/architecture.md) for the project layout and conventions.
